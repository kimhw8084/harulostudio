# Harulo brand system

## Master geometry

The master is immutable and authored once in `lib/brand/geometry.ts`.

- Ring: `cx 47.5`, `cy 41.5`, `r 18.25`, `stroke 7.25`
- Satellite: `cx 68.9`, `cy 29.2`, `r 4.35`
- Primary tier: `30 / 58.5 / 40 × 6.8 / 3.4`
- Secondary tier: `39.2 / 67.6 / 21.6 × 5.5 / 2.75`

Every resting mark and generated asset must resolve to these values.

## Cobalt Ember

Light mode uses Cobalt `#123DFF`, Ember `#FF5C35`, Paper `#F3F5FF`, Ink
`#101322` and Lilac `#B8A7FF`. Dark mode uses art-directed luminous variants.
Cobalt is structure; Ember is the active signal.

## Motion laws

The ring reveals and focuses. The satellite transfers attention. The primary
tier publishes structure. The secondary tier carries metadata and echo. Scenes
sleep when offscreen, pause when hidden or paused, and reduce to static
compositions for reduced-motion and lower-power contexts.
